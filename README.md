# IN6227 Assignment 1 (Variant 1): Decision Tree vs. k-Nearest Neighbors

This repository contains the code for comparing a decision tree and a k-nearest neighbors (KNN) classifier on the IN6227 Assignment 1 dataset. The notebook follows a complete data mining workflow: data understanding, exploratory data analysis (EDA), data cleaning, feature selection and engineering, model-specific preprocessing, hyperparameter tuning, and evaluation on the test set.

## Repository structure

```
IN6227_A1_DT_vs_KNN_G2509000K.ipynb   # full workflow, with all outputs
requirements.txt
figures/                    # plots and test_results.csv generated by the notebook
```

The dataset is not included. To run the notebook, create a folder named `dataset/` next to it and put `train.csv` and `test.csv` inside.

## How to run

1. Install the dependencies: `pip install -r requirements.txt`
2. Put `train.csv` and `test.csv` in `dataset/`.
3. Open the notebook and run all cells. On Google Colab, the second code cell asks you to upload the two files if `dataset/` is missing.

All random processes use `random_state = 42`. The KNN grid search is the slowest step, because every prediction needs distances to all training records.

## Workflow summary

| Step | What is done |
|---|---|
| Data understanding | Attribute types, class imbalance, missing values (including "Unknown"), paired zero values, duplicate data |
| EDA | Correlation heatmap, box plots by label, decile analysis for non-linear relationships, "yes" rate per category, redundancy checks |
| Cleaning and features | Drop records without a label; median/mode imputation; keep "Unknown" as a category; remove the redundant `composite_rank`; add a `perf_zero` indicator; aggregate rare values into "Rare" |
| Preprocessing | Decision tree: imputation + one-hot encoding. KNN: imputation + log transformation of skewed attributes + standardization + one-hot encoding. All steps run inside scikit-learn pipelines to avoid information leakage |
| Tuning | Grid search with stratified 5-fold cross-validation, F1 as the selection criterion |
| Evaluation | Accuracy against a majority baseline, precision, recall, F1, AUPRC, AUC, confusion matrices, precision-recall curves, fit and prediction time |
